# E-Commerce Business Intelligence

## Project Overview

An end-to-end Business Intelligence project analyzing
the Brazilian E-Commerce Public Dataset by Olist.

The objective is to transform raw business data into
actionable insights using SQL and Tableau.

## Business Objectives

- Analyze sales performance.
- Identify high-performing products.
- Understand customer purchasing behaviour.
- Analyze customer retention.
- Evaluate delivery performance.
- Investigate customer satisfaction.
- Provide business recommendations.

## Technology Stack

- Tableau Public
- PostgreSQL
- SQL
- Git
- GitHub

## Dataset

Brazilian E-Commerce Public Dataset by Olist.

Source:
https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce

1. Executive Sales Overview
2. Customer Analytics
